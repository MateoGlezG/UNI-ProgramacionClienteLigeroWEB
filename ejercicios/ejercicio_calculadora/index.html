Un formulario en HTML es un contenedor diseñado para recopilar información del usuario y enviarla a un servidor. Se define mediante la etiqueta <form> y actúa como un puente entre el visitante y la aplicación web, permitiendo desde simples suscripciones hasta complejos sistemas de registro o compras en línea.

Para que un formulario sea funcional, suele incluir elementos como controles de entrada (<input>, <textarea>), etiquetas (<label>) para guiar al usuario, y un botón de envío que inicia el proceso de entrega de los datos.

El evento onsubmit es un manejador de JavaScript que se dispara cuando el usuario intenta enviar el formulario. Es fundamental para la validación de datos (comprobar errores antes del envío) y para el control del flujo, permitiendo detener la recarga de la página mediante event.preventDefault().
